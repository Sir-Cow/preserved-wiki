# 💰 Bundle Auto Funnel

**This mod will allow items that enter your inventory to automatically be sorted in a bundle if you have a bundle that already has that item.**

- Picking up an item that is already in a bundle that is in a player's inventory will put that item into the bundle.
- Shift-clicking an item into an inventory will also automatically place that item its appropriate bundle.
- If an item is moved into the inventory manually, it will not be automatically put into a bundle.

## ⚙️ Modpack Usage

Bundle Auto Funnel is free to be used in any custom mod packs as long as credit is provided. Compatibility with other mods has not been tested for.
